# Delivered Remediation Boundaries

The original severity phases were replaced after revalidation showed that several findings were stale and others crossed independent ownership boundaries. Remediation was delivered through the following cohesive units.

## State Ownership

1. Guard and validate theme persistence without coupling initialization to browser storage availability.
2. Store pending Monte Carlo edits as field intent and rebase them onto the latest controlled configuration.
3. Preserve raw numeric text within each form owner and parse only at its existing commit boundary.

Numeric drafts remain local to their workflows: templates commit on Generate, temporary changes commit on Add, evaluation forms commit on Apply, and canonical tables commit fields on blur or Enter with Escape restoration.

## Table Foundation

1. Make column definitions key-aware without `as never` or row recovery assertions.
2. Require stable row identity from every generic table consumer.
3. Compare editable posting rows to baseline rows by posting ID rather than array position.

## Runtime Boundaries

1. Parse CSV API responses from `unknown` and reject malformed envelopes at the source boundary.
2. Validate worker message discriminators and required envelope fields.
3. Share private worker construction, abort, cleanup, crash, message-error, and posting-failure mechanics while retaining specialized deterministic and progressive stochastic decoding.
4. Extract projection orchestration into a runtime hook invoked by `App` above the route outlet.

Projection hooks remain specialized. Their similar latest-request mechanics were not generalized into a flag-driven public abstraction.

## Presentation Boundaries

1. Route active chart formatting through the shared tested formatters.
2. Extract shortfall cascade construction into a pure presentation adapter.
3. Delete only the seven source files reconfirmed to have no static, dynamic, test, documentation, or barrel consumers.

## Completion Gate

The integrated change must pass typecheck, the full test suite, production build, Biome, `git diff --check`, an independent code review, and a final search for deleted finding links before completion.
