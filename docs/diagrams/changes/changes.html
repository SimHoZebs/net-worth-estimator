8. New tables with no before

Eight tables have no counterpart in your design, one per evaluation plus the timeline rows. Each evaluation gets typed scalar and date columns; variable-length evidence stays verbatim JSON so served output is byte-identical. Projection rows exist because timeline flows and impacts cannot be rebuilt from checkpoints alone without re-simulation.
