Generated with @simhozebs/pele-cli from evaluation-vs-analysis-v2.mmd. Left side (top→bottom) is the synchronous evaluation path: FinancialModel + EvaluationTables → Prepare → Simulate → BuildProjectionPath → NewEvaluationRuntimeSet → EvaluateDeterministic over EvaluationTimeline (projected or historical, source-agnostic) → EvaluationResultTables → shared result renderer → 7 outputs → Frontend. Right side is the independent background analysis: worker claims AnalysisSnapshot (saved bank facts on transaction_source_facts), computes with lease/backoff, persists analysis_findings (identity preserved, dismissed/review), append-only analysis_feedback (requestId idempotency, set-duration), and analysis_promotions (pattern→schedule). Analysis reads FinancialModel only as an anchor; it never touches ProjectionPath or any *_outputs table. Readers and analysis share only the in-memory FinancialModel struct shape; their inputs, lifecycles, storage, and failure modes are disjoint.
